# Security policy

Do not report credentials, private endpoints, identity data, or suspected
vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting form:

<https://github.com/dagoldfish/ansible-collection-minio/security/advisories/new>

Include the affected collection version, module or role, reproduction details,
and potential impact. Remove real credentials and personal data from logs.

Before every release, maintainers must review the complete Git history and the
built Galaxy artifact for credentials, private infrastructure details, and
unexpected generated files. Private vulnerability reporting must remain
enabled while the repository is public.
